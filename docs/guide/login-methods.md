# 登录方式

云族记的登录、注册页面全部自建，一共提供**三种登录方式**。

为什么不止一种？一方面是**平台能力不同**——微信小程序里可以一键授权，H5 网页和 App 则更适合手机号；另一方面是**每个人的隐私偏好不同**：有人不愿意留下手机号，有人记不住密码，长辈则往往只会用微信。三种方式都走同一套账号体系，最终都对应到「一个人、一个账号」，并且可以互相补齐。

不同平台打开登录页时，会**首推**最省事的一种，但随时能切换到另外两种：

- **微信小程序**：首推微信一键登录
- **H5 网页 / App**：首推手机短信验证码登录

## 如何选择

| 登录方式 | 可用平台 | 需要手机号 | 需要记密码 | 适合谁 |
| --- | --- | --- | --- | --- |
| [微信一键登录](#方式一微信一键登录) | 微信小程序 | 否 | 否 | 只用微信、想最省事的人（尤其长辈） |
| [短信验证码登录](#方式二短信验证码登录) | H5 / App / 小程序 | 是（用于接收验证码） | 否 | 不想记密码、习惯用手机号的人 |
| [账号密码登录](#方式三账号密码登录) | 全端 | 否（可后续再绑） | 是 | 不愿暴露手机号、希望凭证自己掌握的人 |

## 方式一：微信一键登录

仅在**微信小程序**中可用，是小程序端的首推方式。

- 点击一次、完成微信授权，就同时完成了**注册和登录**，无需填写账号、密码、手机号，也不用图形验证码
- 系统识别到是新微信用户时会自动建号并发凭证，所以不存在「先注册再登录」两步
- 最适合长辈，或不想填写任何表单、希望扫码即用的人

**一个建议**：微信一键登录后，可在小程序内顺手绑定手机号（入口在「我的 → 安全 → 手机号」）。这样以后在 H5 网页上也能用短信登录到同一个账号，账号也多一条找回途径。

## 方式二：短信验证码登录

在 **H5 网页和 App 上首推**，微信小程序里也可作为备选。

- 输入手机号 → 完成一次「点选文字」图形验证 → 获取短信验证码 → 填入即可登录，**不需要记密码**
- 新手机号第一次登录会**自动注册**（登录即注册），老手机号则直接进入原账号，不会重复建号
- 适合不想记密码、平时习惯用手机号收验证码的人

安全上做了这些处理：

- 短信验证码**一次性使用**、短时效（约 5 分钟）
- 发码前需通过图形验证码，防止脚本批量请求
- 同一设备、同一 IP 设有每日发送上限，发送按钮带倒计时，不能重复并发点击
- 短信通过阿里云「号码认证服务」下发，验证码由服务端生成与校验

需要注意：这种方式要求手机号能正常接收短信。

## 方式三：账号密码登录

**全平台可用**，是唯一不依赖手机号、也不依赖微信的方式。

- 用「账号 + 密码」登录；账号绑定过手机号后，也支持用「手机号 + 密码」登录
- 同样是**登录即注册**：当输入的账号在库里不存在时，完成一次图形安全验证，就会自动创建这个账号并直接登录，不需要单独的注册页
- 当你**不想暴露手机号信息**时，可以用这种方式完成注册和登录。流程可能稍显繁琐，但账号密码由自己保留、不依赖手机号或第三方授权，凭证完全自己掌握

请注意记好账号和密码：密码至少 8 位，建议字母与数字组合。若日后忘记密码，可在登录页点「忘记密码」，通过已绑定的手机号短信验证后重置。

## 三种方式互通吗？

互通。它们是**同一套账号**，不是三个互不相通的号：

- 账号密码登录的账号，可以再绑定手机号
- 手机号登录的账号，可以再设置密码
- 微信一键登录的账号，建议在小程序内绑定手机号

这样设计是为了保证「一个人始终是一个账号」，不会因为换了一种登录方式就被重复建档。

> 提醒：如果在**没有绑定手机号、也没有设置密码**的情况下就换到另一端（例如微信登录后直接去 H5），系统可能无法识别为同一人，从而产生重复账号。因此建议登录后顺手把手机号或密码补齐。

## 忘记密码、绑定手机与注销

| 需求 | 入口 | 说明 |
| --- | --- | --- |
| 找回 / 重置密码 | 登录页「忘记密码」 | 通过手机号短信验证后设置新密码，成功后需用新密码重新登录 |
| 绑定手机号 | 我的 → 安全 → 手机号 | 未绑定可凭短信验证码绑定；已绑定只显示脱敏号码 |
| 修改密码 | 我的 → 安全 → 修改密码 | 按账号状态自动分流：有密码则改密码、无密码有手机号则凭短信设密码 |
| 注销账号 | 我的 → 安全 → 注销账号 | 只标记账号关闭，不会删除族谱中的关系记录 |
