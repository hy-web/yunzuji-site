# 家族事务（建设中）

::: warning 这个模块还在建设中
家族事务是云族记的**第二大模块**，目前正在持续开发与打磨，部分能力和界面可能调整。本页描述的是它的定位与规划方向，最终形态以应用内为准。
:::

## 为什么需要第二个模块

理清"谁和谁是什么关系"只是家族管理的一半。一个家族在日常运转中还会产生大量**事务性内容**：

- 红白喜事、祭祖、聚会的通知与纪事
- 家族长辈的口述、老照片、生平资料
- 祠堂修缮、族谱编修等公共开支与份子钱
- 需要通知到每个人、并确认"大家都看到了"的事情

这些不适合塞进族谱关系结构里，因此云族记把它们独立成「家族事务」模块，与「人际关系」并列。它在应用底部导航栏中是一个独立的主入口（**记录**）。

## 模块边界

```
云族记（家族管理应用）
├── 人际关系模块            记录"谁是谁"——关系网络、称呼、身份、权限
│      └── 详见 人际关系画布 / 称呼引擎 / 权限模型
└── 家族事务模块（本页）     记录"发生了什么"——纪事、资料、收支
       └── 与族谱关系数据相互独立，不影响关系结构
```

两个模块共享同一套账号、家族与权限体系（谁是本族人、谁是管理员、谁有访问权），但**数据各自独立**：删掉一条事务记录不会影响族谱，反之亦然。

## 规划与在建能力

**图文家族纪事**

- 管理员发布家族动态、通知、纪事，支持文字与图片
- 成员在时间线里浏览，点进详情阅读
- 图片以画廊形式浏览，便于沉淀老照片与活动影像
- 已读反馈：发布者能看到**谁看过**这条记录，重要通知不会"发了没人知道看没看"
- 管理员可把过期记录归档，列表在「已发布 / 已归档」间切换

**家族收支**

- 记录家族公共收入与支出（如聚餐 AA、修缮公摊、份子钱）
- 与图文纪事分开管理，账目和事情不混在一起

**权限沿用族谱体系**

- 只有本家族管理员能发布 / 编辑 / 归档事务
- 普通成员浏览与查看已读情况
- 外族人的可见范围同样受家族开放档位约束

## 后续方向

- 纪事与具体成员 / 事件挂钩（例如把一张老照片关联到族谱里的某位祖先）
- 纪念日、生日、忌日等时间提醒
- 更丰富的收支统计与公示
