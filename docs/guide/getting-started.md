# 快速上手

本文带你在本地跑起云族纪，适合想先体验或参与开发的人。

## 环境准备

- **HBuilderX**：云族纪基于 uni-app（Vue 3）开发，官方推荐使用 HBuilderX 编译
- **uniCloud 账号**：用于创建阿里云服务空间（数据库、云函数、云存储都在上面）
- **Node.js**：仅在需要命令行构建时使用

## 三步跑起来

### 1. 获取代码

从代码仓库克隆或下载源码，用 HBuilderX 打开项目根目录。

### 2. 创建云服务空间

1. 登录 [uniCloud 控制台](https://unicloud.dcloud.net.cn/)
2. 创建一个**阿里云**服务空间
3. 在 HBuilderX 中右键 `uniCloud-aliyun` 目录，关联刚创建的空间
4. 右键 `database` 目录，上传所有 DB Schema（表结构会自动创建）
5. 右键 `cloudfunctions` 目录，上传所有云函数

### 3. 补充配置并运行

1. 复制配置文件模板，填入你自己的服务空间信息，保存为 `config.json`
2. 在 HBuilderX 中选择「运行 → 运行到浏览器」
3. 看到登录页即说明环境正常；注册第一个账号后，该账号会成为本家族的管理员（role 为 admin）
