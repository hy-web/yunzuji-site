# 云族记是什么？

云族记是一个**家族管理应用**。很多人第一次听说会以为它只是一张电子族谱，但族谱（人际关系）其实只是它的第一个、也是目前最完整的一个模块。

## 两个模块，管一个家族的两件事

一个家族在长期运转中有两类核心信息：

| | 回答的问题 | 内容 | 状态 |
| --- | --- | --- | --- |
| **人际关系模块** | "谁是谁" | 族谱关系网、配偶外亲、自动称呼、身份认领、隐私权限 | 核心模块，已完整 |
| **家族事务模块** | "发生了什么" | 图文纪事、老照片、已读反馈、家族收支 | 建设中 |

两者共享同一套账号、家族与权限体系，但数据相互独立：删一条事务记录不会动族谱，整理族谱也不会影响纪事。

## 传统族谱软件的问题

人际关系这部分，大多数工具画的是一棵"树"——从上到下，父传子、子传孙。这在传统父系社会里够用，但现实中的家族关系远比树复杂：

- 一个人可能嫁过来、又在自己娘家是女儿，**同时在两个家族里有身份**
- 表亲、姻亲、外亲——这些关系在纯父系树上根本画不出来
- 多段婚姻、同族婚姻、跨代配偶等真实情况，会让严格的树结构直接报错
- 录错了一个人，删也不是、改也不是，因为数据已经牵连到其他人
- 长辈上手难，一次误删可能让不可再生的资料永久丢失

## 云族记的思路

云族记不是画一棵树，而是**记录一张关系网**：

- **父系谱系是骨架**——按辈分、排行、血缘整齐排列
- **配偶和外亲是延伸**——嫁过来的人有配偶身份，外嫁 / 外娶带来的亲属有外亲身份
- **分身机制**——一个真人在不同家族有不同节点，通过分身关联到同一个人
- **自动称呼**——任意两个节点之间，自动推算"堂哥、表姐、姑父、二嫂"这类准确称呼
- **两种视图 / 两种布局**——可切到只看本家男性的传统族谱模式，也可在纵向、横向布局间切换
- **归档可逆**——任何操作都有快照，误操作可以撤销，删除还能短暂恢复
- **隐私分层**——同一棵树，外族人、配偶、本家人看到的版本各不相同

## 一个直观的例子

假设陆家的女儿嫁到黄家：

- 她在**陆家**的树上，是"陆家三女儿"
- 她在**黄家**的树上，是"黄家的儿媳 / 配偶"
- 这两个节点背后是**同一个真人**，资料只存一份
- 她登录后可以选择默认先看哪个家族
- 她在黄家看到的称呼（丈夫的父母是"公公婆婆"）、在陆家看到的称呼（自己的父母是"爸妈"）都会自动算对

传统软件只能让你二选一，云族记让两种身份同时成立。

## 适合谁用？

- 想认真记录自己家族成员关系与日常事务的人
- 觉得传统族谱软件太死板、画不出真实婚姻与跨家关系的人
- 担心录错数据无法挽回、希望长辈也敢放心操作的人
- 希望数据掌握在自己手里、而不是交给某个商业平台的家庭

## 不适合谁？

- 只想要一棵整齐划一、不体现婚姻关系的父系树——云族记画的是网（不过它也提供"只看本家男性"的族谱模式）
- 想做一个完全公开、任何人都能注册浏览的族谱社区——云族记是私有部署
- 希望 SaaS 开箱即用、完全不想配置云空间——部署需要花十几分钟做一次性配置（有[部署指南](./deployment)）
