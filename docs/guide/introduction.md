# 云族纪是什么？

云族纪是一个**家族族谱应用**，但它和你见过的其他族谱软件不太一样。

## 传统族谱软件的问题

大部分族谱工具画的是一棵"树"——从上到下，父传子、子传孙。这在传统父系社会里够用，但现实中的家族关系比树复杂得多：

- 一个人可能嫁过来、又嫁过去，同时在两个家族里有身份
- 表亲、姻亲、外亲——这些关系在纯父系树上根本画不出来
- 录错了一个人，删也不是、改也不是，因为数据已经牵连到其他人了

## 云族纪的思路

云族纪不是画一棵树，而是**记录一张关系网**：

- **父系谱系是骨架**——按辈分、排行、血缘排列
- **配偶和外亲是延伸**——嫁过来的人有配偶身份，外嫁的人有外家身份
- **分身机制**——一个真人在不同家族有不同的节点，通过分身关联起来
- **归档可逆**——任何操作都有快照，误操作可以撤销

## 适合谁用？

- 想记录自己家族成员关系的人
- 觉得传统族谱软件太死板、画不出真实关系的人
- 担心录错数据无法挽回的人

## 不适合谁用？

- 想要一棵完美的、整齐的树——云族纪画的是网
- 想公开给所有人看——云族纪是私有部署，只给自家人用
- 想要 SaaS 一键注册即用——需要自己部署 uniCloud 空间
