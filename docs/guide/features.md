# 功能亮点

云族记是一个**家族管理应用**，而不只是一张电子族谱。它围绕家族日常的两大需求组织成两个模块：**人际关系**（理清"谁是谁"）和**家族事务**（记录"发生了什么"），并由统一的账号、权限和数据能力支撑。

```
云族记
├── 人际关系模块   关系网络 · 自动称呼 · 身份认领 · 隐私权限
└── 家族事务模块   活动记录册 · 图文照片 · 收支台账
```

## 模块一：人际关系

这是云族记的核心模块，用一张可缩放的关系画布管理整个家族网络。

### 记录一张"关系网"，而不是一棵树

- 父系血亲按辈分、排行、血缘整齐排列，作为骨架
- 配偶以"分身"节点接入并画婚姻连线，外亲子女随母亲呈现
- 不限制婚姻形态：多段婚姻、同族婚姻、跨代配偶都能如实记录
- 一个真人在不同家族有不同身份节点，资料只存一份、处处同步，还能单独匿名某个家族里的自己

详见[技术架构 · 数据模型](./architecture#数据模型一个人为什么有三种-id)。

### 画布上的查看与操作

- **两种视图**：完整模式（所有人与婚姻关系）/ 父系族谱模式（仅本家男性血亲，传统族谱观感）
- **两种布局**：纵向（根在上）/ 横向（根在左、后代向右），一键切换
- **关系任意匹配**：任选画布上两个人（可切换其分身），即时显示双向称呼并高亮关系路径
- 双指缩放、平移、搜索、一键定位"我"、节点样式切换、近亲识别矩形
- 长按节点弹出菜单：添加上级 / 子嗣 / 配偶、编辑、认领、分身管理、删除等
- 待认领成员放在等待区，可直接拖拽上树
- 整张族谱可导出为图片，大家族支持分页打包

完整导览见[人际关系画布](./canvas)。

### 自动推算亲属称呼

任意两个节点之间自动算出准确的中文称呼——堂哥、表姐、姑父、二嫂、外孙、连襟，覆盖父系 / 母系、血亲 / 姻亲、长辈 / 平辈 / 晚辈、排行与性别组合，双向各算一次。性别未知时不硬猜，宁可留空也不叫错。详见[称呼计算引擎](./kinship-engine)。

### 称呼体系可切换、可自建

称呼引擎只负责算出"关系位置"，"这个位置叫什么"可以整族替换：

- **多套体系一键切换**：内置「中国通用版」，家族改选别的体系后，称呼立刻整体更换
- **逐条改词、排行可控**：每条称呼可单独改字，并能独立开关"大 / 二 / 三"排行前缀
- **自建与复制**：管理员可新建一套称呼（只写要改的词，其余沿用），也能把别族公开体系复制一份再改
- **个人自定义称呼**：每个人还能对某个节点设置只对自己生效的私人叫法
- 体系没写到的称呼直接显示姓名，不会出现"一半中文一半外语"

### 真人认领与身份认证

族谱常由管理员先批量录入（未注册的"模拟登记"节点），真人注册后把自己认领到对应节点：

- 系统给出候选，本人确认后**合并**（真人账号保留、模拟登记被吸收，关系不断）
- 家族可设"自证题"（如祖源地），防止同名同姓误认
- 添加配偶时若对方已有账号，自动建立关联

### 归档可逆，误删可恢复

添加、修改、删除、认领、批量导入全部自动写归档快照，支持撤销；被删成员短时间内以"虚影"留在画布可一键恢复；批量导入可整批回退。详见[权限与隐私模型 · 归档与撤销](./permission#归档与撤销)。

### 多层权限与隐私

同一棵树，不同人看到不同版本：家族开放三档（开放 / 半开放 / 封闭）、半开放下的近亲实名窗口、逐人特批名单、分身匿名、以及数据出口的 id 净化（抓包也反推不出匿名者）。详见[权限与隐私模型](./permission)。

## 模块二：家族事务

家族除了关系，还有大量事务性内容需要沉淀，这是底部导航里独立的「记录」模块。它被设计成**一本对全家族公开的活动记录册**，而不是通知 / 审批系统：

- **一张记录纸**：管理员以信纸形式发布活动纪事（标题、正文、记录人），成员打开是同款只读纸面
- **活动详情与照片**：一条活动可持续追加多条进展，每条配文字与照片（画廊浏览，最多 20 张）
- **收支台账**：区分收入 / 支出，记用途与金额；管理员记账或代填，成员也能自助登记自己的那一笔（一人一笔）
- **已读与存档**：能看到谁看过；过期活动存档后只读但仍全员可见，可恢复
- 与族谱数据相互独立，共享同一套账号与权限；刻意保持极简，不做会计科目、统计报表与审批流

完整介绍见[家族事务](./family-affairs)。

## 平台级能力

### 数据导入导出

- **CSV 批量导入**：按模板填好整族导入，先出预览报告、确认后才写库，可整批撤销
- **全族导出**：随时导出 CSV 备份到自己手里
- **GEDCOM 兼容**：支持把通用家谱格式（5.5.1 / 7.0）转换后导入

### 多端可用

基于 uni-app，一套代码交付**微信小程序**（长辈扫码免密即用）、**H5 网页**（便于分享）和 **App**。

### 多种登录方式

登录注册页全部自建，提供**微信一键登录、短信验证码登录、账号密码登录**三种方式：不同平台首推最省事的一种，其余作为备选，三种方式还能互相补齐为同一个账号。各方式的适用场景、隐私取舍与配套账号管理，详见[登录方式](./login-methods)。

### 「我的」页面 · 登录前后

「我的」是整个应用的功能导航中心。未登录时，三个主页面都采用**书法 Logo 空态**——一句提示 + 登录入口，不堆无意义功能（首页「族」、记录「记」、我的「我」）；登录后按「家族功能 / 设置 / 安全」分组，入口一目了然。

### 深色模式与 AI 助手

- **深色模式**：全站支持浅色 / 深色一键切换，古籍暖棕风在夜间同样柔和、不刺眼
- **家谱 AI 助手**：用大白话提问——"家里有多少人""有没有叫某某的人""这个人是我的谁"，即时给出答案

### 私有部署，数据属于自己

- 不上架公开市场、不开放公共注册，每个家族部署自己的云空间
- 成员数据只存在自己的库里，免费额度即可支撑几十到上百人家族
- 适合想认真记录、又不希望家族资料交给商业平台的家庭

部署步骤见[部署指南](./deployment)。
