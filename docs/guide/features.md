# 功能亮点

## 分身体系

一个真人在不同家族有不同的身份节点。

比如：一个女性嫁入黄家，她在黄家是"黄家长媳"，在自己娘家是"陈家三小姐"。传统族谱软件只能选一边——要么只记她在黄家的身份，要么只记她在陈家的身份。

云族纪的分身机制：
- 每个家族里有她的一个节点（身份）
- 这些节点通过分身关联到同一个真人
- 从哪个家族登录，就看到哪个身份
- 分身可以匿名——别人看不到你的全名，保护隐私

## 归档可逆

族谱数据不可再生——人去世了就没法再录了。所以云族纪的核心设计原则是：**任何操作都能撤销**。

- 添加、修改、删除成员 → 自动写归档快照
- 认领身份 → 归档后可撤销
- 导入批量数据 → 整批撤销
- 撤销就是恢复到操作前的状态，不留垃圾数据

## 多层权限

同一棵家族树，不同的人看到的版本不一样：

| 角色 | 能看到什么 |
|------|-----------|
| 本家族管理员 | 全图，所有成员 |
| 本家族成员 | 本家族全图 |
| 已认证配偶 | 本家族 + 配偶的本家 |
| 特批访问者 | 按特批名单的范围 |
| 外族人 | 封闭家族看不到，半开放家族只能看近亲 |

服务端在返回数据前做了三层过滤：访问控制 → 内容等级 → 匿名节点 ID 净化。前端拿到的就是给他定制好的版本。

## 自定义 Canvas 可视化

族谱树用 Canvas 自绘，支持：
- 缩放、平移、点击聚焦
- 节点长按弹出操作菜单
- 双指缩放以触点为中心
- 离屏渲染缓存优化性能

## CSV 批量导入导出

- 支持 CSV 批量导入家族成员
- 支持导出为 CSV（含祖源地、家姓等列）
- 导入有预览报告，确认后才提交
- 支持整批撤销
- 兼容 GEDCOM 格式转换（.ged → CSV）
