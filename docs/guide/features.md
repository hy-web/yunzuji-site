# 功能亮点

这一页从产品视角介绍云族纪能做什么。想了解背后的技术实现，每节末尾都附有技术深潜链接。

## 记录一张"关系网"，而不是一棵树

传统族谱软件画的是一棵从上到下的父系树。但现实里，一个人会嫁过来、又在自己娘家是女儿，会有外亲、姻亲、跨代婚姻——这些在纯树上根本画不出来。

云族纪以**父系谱系为骨架**，把配偶、外亲作为延伸挂接上去，形成一张真实的关系网：

- 父系血亲按辈分、排行、血缘整齐排列
- 配偶以"分身"节点接入，画婚姻连线
- 外亲子女随母亲呈现，跨家族也能追溯
- 不限制婚姻形态：多段婚姻、同族婚姻、跨代配偶都能如实记录

技术实现见 [技术架构 · 数据模型](./architecture#数据模型一个人为什么有三种-id)。

## 分身体系：一个真人，多个家族身份

一个真人在不同家族有不同的身份节点，但资料只存一份：

- 一位女性嫁入黄家，她在黄家是"长媳"，在娘家仍是"三小姐"——两个节点指向同一个人
- 从哪个家族登录，就默认看到自己在那个家族的身份
- 可以把某个家族里的自己**匿名**，也可以指定在每个家族默认以哪个分身出现
- 改一次个人资料，所有家族里的她同步更新

## 自动推算亲属称呼

不需要手动标注每个人和你的关系。在任意两个节点之间，系统自动算出准确的中文称呼：堂哥、表姐、姑父、二嫂、外孙、连襟……

- 支持父系/母系、血亲/姻亲、长辈/平辈/晚辈、排行、性别组合
- 双向称呼：既能看到"我该叫他什么"，也能看到"他该叫我什么"
- 关系匹配工具可以选中两个人，展示他们之间的完整关系路径
- 性别未知、关系存疑时不硬猜，宁可留空也不叫错

这是全项目技术密度最高的模块，详见 [称呼计算引擎](./kinship-engine)。

## 真人认领与身份认证

族谱往往先由管理员批量录入（很多成员还没注册），这些是"模拟登记"节点。真人注册后，可以把自己**认领**到对应的节点上：

- 系统按姓名、家族等条件给出候选，本人确认后完成认领
- 认领是**合并**：真人账号保留，原来的模拟登记被吸收，关系不断
- 家族可设置一道"自证题"（如祖源地），防止同名同姓的人误认领
- 支持对称互认：添加配偶时若对方已有账号，自动建立关联

## 归档可逆：怎么删都能恢复

族谱数据不可再生，因此系统把"可撤销"作为架构级原则，而不是事后补救：

- 添加、修改、删除、认领、批量导入，全部自动写归档快照
- 支持撤销认领、撤销定位、整批撤销导入
- 被删成员短时间内以"虚影"留在画布上，可一键恢复
- 撤销是恢复到操作前的完整状态，不残留垃圾数据

详见 [权限与隐私模型 · 归档与撤销](./permission#归档与撤销)。

## 多层权限与隐私保护

同一棵树，不同的人看到不同的版本：

| 角色 | 能看到什么 |
| --- | --- |
| 本家族管理员 | 全图、所有成员、治理操作 |
| 本家族成员 | 本家族完整关系 |
| 已认证配偶 | 本家族 + 自己配偶的本家 |
| 特批访问者 | 按管理员逐人授权的范围 |
| 外族人 | 依家族开放档位：全图 / 仅近亲 / 完全不可见 |

配套能力包括：家族三档开放级别、半开放下的"近亲实名窗口"、分身匿名、以及数据出口的 id 净化（防止抓包反推出匿名者身份）。详见 [权限与隐私模型](./permission)。

## 族谱画布可视化

族谱用 Canvas 全自绘，针对手机操作做了专门优化：

- 双指缩放（以触点为中心）、单指平移、点击节点聚焦
- 长按节点弹出操作菜单（添加上级/子嗣/配偶、编辑、认领、删除等）
- 配偶覆盖矩形、分身连线、近亲关系提示等专属视觉
- 待认领成员放在"等待区"，可直接拖拽上树
- 离屏渲染缓存，保证较大家族也能流畅绘制
- 支持整张导出为图片，或分页打包导出

## 数据导入导出

考虑到家族资料常常已经存在于 Excel 或其他家谱软件中：

- **CSV 批量导入**：按模板填好即可整族导入，导入前先出预览报告，确认后才写库
- **整批可撤销**：导入错了可以一键回退整批数据
- **CSV 导出**：随时导出全族数据备份，含祖源地、家姓等字段
- **GEDCOM 兼容**：可将通用家谱格式 GEDCOM（5.5.1 / 7.0）转换后导入
- 导入过程在服务端两遍写库，先建人、再补关系，避免半成品数据

## 家族内部记录

除了族谱本身，还提供家族内部的图文记录能力：

- 管理员发布家族动态、纪事，支持图文和收支记录
- 已读状态，能看到谁看过
- 记录与族谱数据相互独立，不影响关系结构

## 多端可用

基于 uni-app，一套代码同时交付：

- **微信小程序**：免密登录，长辈最容易上手，扫码即用
- **H5 网页**：浏览器直接访问，便于分享
- **App**：打包成独立手机应用

## 私有部署，数据属于自己

- 不上架公共应用市场、不开放公开注册
- 每个家族部署自己的云空间，成员数据只存在自己的库里
- 免费的云服务额度即可支撑几十到上百人的家族
- 适合想认真记录、又不希望家族资料交给商业平台的家庭
